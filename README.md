# urbanmobility_economicproductivity
Analyzed traffic (TomTom) &amp; economic data (OECD) across 15 LatAm cities to evaluate mobility vs. productivity. Correlation analysis shows congestion is strongly driven by population (r=0.88) and inversely tied to unemployment (r=-0.69), but weakly to GDP/capita (r=0.28). Identified Bogotá and Lima as priority transit investment targets.
